About Optimization

Optimizing a website means making it load faster for users. In this experiment, I implemented three common techniques:

  • Image Lazy Loading: Defers loading off-screen images until the user scrolls down to them.
  • Browser Caching: Saves static files locally in the browser so they do not need to be downloaded again.
  • CSS Minification: Removes extra spaces and comments to make files smaller.

3. CSS Minification

Minifying removes all spaces, line breaks and comments. Here is an example from this project:

Before Minification (Readable)

body {
  font-family: Arial;
  margin: 0;
  color: #333;
}

After Minification (Compressed)

body{font-family:Arial;margin:0;color:#333}
