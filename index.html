3. CSS Minification

Minifying removes all whitespace, line breaks, and comments to reduce file size:

Before Minification (Readable)

body {
  font-family: Arial;
  margin: 0;
  color: #333;
}

After Minification (Compressed)

body{font-family:Arial;margin:0;color:#333}
