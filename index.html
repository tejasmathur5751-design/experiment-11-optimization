1. Browser Caching

What is Caching?
Caching stores copies of files locally in the browser so they don't have to be downloaded again on repeat visits. This reduces server load and makes the page load faster.
Cache-Control Headers (Express.js)
server.js
const express = require('express');
const app = express();

// Serve static files with caching for 1 day (86400 seconds)
app.use(express.static('public', {
  maxAge: '1d',          // Cache static assets for 1 day
  etag: false            // Disable ETag for simpler caching
}));

// Cache-Control header for specific routes
app.get('/api/data', (req, res) => {
  res.set('Cache-Control', 'public, max-age=300'); // 5 minutes
  res.json({ message: 'This response is cached for 5 minutes' });
});

app.listen(3000);
Service Worker for Offline Caching
sw.js
const CACHE_NAME = 'my-site-v1';
const FILES_TO_CACHE = ['/', '/index.html', '/style.css', '/script.js'];

// Install: cache all files
self.addEventListener('install', function(e) {
  e.waitUntil(caches.open(CACHE_NAME).then(cache => cache.addAll(FILES_TO_CACHE)));
});

// Fetch: serve from cache if available, else fetch from network
self.addEventListener('fetch', function(e) {
  e.respondWith(
    caches.match(e.request).then(response => response || fetch(e.request))
  );
});

2. CSS and JavaScript Minification

Minification removes unnecessary whitespace, comments and long variable names from CSS/JS files. This reduces file size and speeds up download time.
Before Minification (normal CSS)
style.css (original – 180 bytes)
/* Page body styles */
body {
  font-family: Arial, sans-serif;
  margin: 0;
  background-color: #f4f4f4;
  color: #333;
}
After Minification (minified CSS)
style.min.css (60 bytes – 67% smaller)
body{font-family:Arial,sans-serif;margin:0;background-color:#f4f4f4;color:#333}
Script Loading Optimization
index.html
<!-- defer: script loads in background, runs after HTML is parsed -->
<script src="script.min.js" defer></script>

<!-- async: script loads and runs as soon as downloaded (for independent scripts) -->
<script src="analytics.min.js" async></script>

3. Lazy Loading of Images

Lazy loading delays loading of images until they are about to enter the viewport. This reduces initial page load time, especially for pages with many images.
HTML Native Lazy Loading
index.html
<!-- loading="lazy" tells the browser to load only when near viewport -->
<img src="photo.jpg" alt="Photo description" loading="lazy" width="600" height="400">

<!-- loading="eager" (default) loads immediately -->
<img src="hero.jpg" alt="Hero image" loading="eager" width="1200" height="600">
